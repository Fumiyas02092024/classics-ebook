# 三つの旅　ホメロス・プラトン・ダンテ

西洋古典の三つの代表作を、現代の日本語で読めるように再話した電子書籍です。スマートフォンでオフラインのまま読めます。

- **第一部　ホメロス**：『イリアス』『オデュッセイア』
- **第二部　プラトン**：『饗宴』『国家』（洞窟の比喩）『ソクラテスの弁明』『クリトン』『パイドン』
- **第三部　ダンテ**：『神曲』地獄篇・煉獄篇・天国篇

全訳ではありません。核となる場面を選び、場面の中では出来事の順序・台詞・比喩をできるだけ原典に沿わせています。省いた部分は〔　〕であらすじとしてつないでいます。本文は約12.7万字、全30章です。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `dist/三つの旅_縦書き.epub` | 縦書きEPUB（Apple ブック、Google Play ブックなど） |
| `dist/三つの旅_横書き.epub` | 横書きEPUB |
| `dist/三つの旅.html` | ブラウザで読める単体HTML（目次・文字サイズ・夜間表示・読書位置の記憶） |

### スマホで読む

- **iPhone**：EPUBをAirDropで送り、「ブック」アプリで開く
- **Android**：EPUBをGoogle Play ブックにアップロードし、オフライン用にダウンロードする

## ビルド

本文は `src/*.txt` にあります。編集後、次のコマンドで3形式すべてを作り直します（Python 3 と Pillow が必要）。

```bash
python3 build.py
```

### 原稿の記法

| 記法 | 意味 |
| --- | --- |
| `# 見出し` | 章（EPUBでは1ファイル） |
| `## 見出し` | 節 |
| `> 行` | 詩行・碑文 |
| `〔……〕` で始まる段落 | 省略部分のあらすじ |
| `※` で始まる段落 | 読者向けの補足（章の冒頭では出典表示） |
| `【名前】台詞` | 対話篇の話者つき台詞 |
| `- 項目` | 箇条書き |
| `---` | 場面の区切り |

縦書きでは半角英数字が横倒しになるため、本文では全角を使ってください。
